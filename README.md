# 알바 스케줄 추천 (데모 웹앱)

기획서 `알바-스케줄-추천-기획서.md` 기반. 빌드 없이 실행되는 정적 웹앱.

## 실행
`실행.bat` 더블클릭 → 브라우저에 http://127.0.0.1:5190 이 열립니다. (Python 3 필요)

## 구조
- `index.html` — 진입점 (Pretendard 폰트, html2canvas CDN)
- `css/style.css` — 스타일
- `js/data.js` — 지역 15곳, 이동시간 15×15 매트릭스, 목데이터 공고 72건(시드 고정, 데모용 8건 의도 배치)
- `js/engine.js` — 빈 슬롯 계산 · 이동 가능 후보 필터 · 조합 3안(수입/여유/밸런스) · 검증 · 실질 시급
- `js/app.js` — 해시 라우터 + 화면 (온보딩 / 홈 / 결과 / 스케줄 상세 / 내 스케줄)

## 화면
| 경로 | 내용 |
|---|---|
| `#/onboarding` | 4스텝 (신분 → 고정일정(매일 같음 토글) → 집·제약 → 목표금액) |
| `#/` | 탐색 조건 + 빈 시간 프리뷰(하단 고정) |
| `#/result` | **왼쪽: 추천 결과 기록(최근 30건, 클릭 시 재열람·삭제)** · 3안 카드 → 주간 시간표(고정=회색, 이동=빗금) → 상세·연락처(tel:) · 핀 고정/제외 재생성 |
| `#/schedule/:id` | 저장본 수정(시간 변경·삭제 → 즉시 검증 경고), PNG 이미지 저장 |
| `#/my` | localStorage 저장 목록 |

## 참고
- LLM 호출 대신 코드 엔진이 3안을 산출합니다(기획서 9-4의 fallback 로직). `generatePlans()`에 LLM 응답을 끼워 넣으면 됩니다.
- 공고 데이터를 교체하려면 `js/data.js`의 `JOBS`를 같은 스키마의 JSON으로 바꾸면 됩니다.
