# Daytona 사용 이유 — 현재 제품 기준

## 20초 답변

“600개 Mock 공고를 계산하는 데 Daytona만이 가능한 것은 아닙니다.
우리가 검증한 것은 추천 에이전트의 실행 경계입니다. 웹 요청을 받으면 Daytona가
실제로 전체 데이터 로딩, 정규화, 시간·이동 제약 검사와 후보 일정 생성을 수행합니다.
컨트롤러는 그 결과로 적합도를 평가하고 화면에 전달합니다.
이번 MVP에서는 이 원격 실행 경로가 실제로 동작하는 것을 보여줍니다.”

## 공격 질문과 답변

**“그냥 로컬 Python으로도 되잖아요?”**

맞습니다. 현재 크기에서는 로컬이 더 단순하고 빠를 수도 있습니다.
Daytona 선택 이유는 이 계산 자체의 독점적 필요성이 아니라, 계획 도구를 웹 서버와
분리한 실행 구조를 검증하기 위해서입니다. 같은 인터페이스의 로컬 개발용 runtime도
있습니다. 현재 웹 라이브 경로의 기본값은 실제 Daytona이며 조용히 로컬로 대체하지 않습니다.

**“후원사 로고 붙이려고 Hello World만 실행한 것 아닌가요?”**

아닙니다. 서버가 Harness 코드와 원본 600개 데이터셋을 sandbox에 전달하고,
그곳에서 후보 일정과 수입을 계산해 JSON으로 회수합니다.
웹 화면의 후보 개수, 일정, 수입은 그 실행 결과를 사용합니다.
SDK 호출만 제거하면 현재 라이브 요청은 성공하지 않습니다.
별도의 로컬 runtime으로 코드를 바꾸면 실행 가능하다는 것과는 구분해야 합니다.

**“Mock 데이터인데 왜 sandbox죠?”**

Mock은 입력 데이터의 출처입니다. 실행 경계까지 Mock으로 만든 것은 아닙니다.
정해진 입력 덕분에 동일한 계획 도구가 원격에서도 올바른 결과를 내는지 재현할 수 있습니다.
현재 크롤링은 없고, 향후 도구 확장의 기반이라는 설명은 가능하지만 구현 완료라고 주장하지 않습니다.

**“실제로 뭐가 분리됐나요?”**

Daytona 안: jobs.json 로딩, 정규화, 모집 상태·요일·시간·이동·자격·제외 조건 검사,
후보 일정과 예상 수입 생성.
컨트롤러: 입력 검증, 후보 적합도 점수, 최종 선택, HTTP 응답.
브라우저: 조건 입력과 결과 표시.
Nosana는 선택 기능이며 현재 피치는 결정론적 순위로도 실행됩니다.

**“느리고 장애 지점만 늘린 것 아닌가요?”**

원격 실행에는 네트워크 지연과 서비스 의존성이 추가됩니다. 이 비용을 인정합니다.
데모에서는 sandbox 하나를 재사용하고, 서버는 25초 응답 대기 후 명시적인 오류를 반환합니다.
실패를 숨겨서 로컬 결과를 원격 실행인 것처럼 제시하지 않습니다.
현재 관측된 빠른 실행 시간이 운영 SLA나 부하 처리 성능을 입증하지는 않습니다.

**“보안이 얼마나 좋아졌는데요?”**

도구 프로세스를 컨트롤러 밖에서 실행하는 경계가 생겼다는 것까지 확인했습니다.
네트워크 allowlist, 세밀한 권한, 악성 코드 안전성, 개인정보 보호 인증은 검증하지 않았습니다.
코드와 데이터가 외부 실행 환경으로 전달되므로 실제 개인정보를 다루면 별도 검토가 필요합니다.

## 화면으로 증명하기

1. `http://127.0.0.1:5191/#/live`에서 추천 실행.
2. 데이터 600개 → 모집 중 546개 → 조건에 맞는 후보 개수 표시.
3. “실행 근거와 주의사항”에서 sandbox ID와 실행 trace 확인.
4. “실제 응답 JSON”에서 `meta.runtime_provider=daytona`, `execution_ok=true`, `execution_proof` 확인.
5. 선호를 바꾸어 실제 후보의 선택이 달라지는 것 확인.

Sandbox ID만으로는 충분한 증명이 아니다. 실제 remote command의 성공, 처리 개수,
반환된 후보와 최종 일정의 연결을 함께 보여준다.

## 피해야 할 주장

- “Daytona가 없으면 이 계산은 불가능하다.”
- “실시간 여러 구인 사이트를 크롤링한다.”
- “현재 배포된 모든 추천 화면이 Daytona를 사용한다.” (라이브 데모 경로가 대상)
- “모든 작업이 sandbox 안이다.” (최종 적합도 평가는 컨트롤러)
- “Nosana AI가 반드시 추천한다.” (선택 기능, deterministic fallback)
- “격리·보안·확장성이 운영 수준으로 입증됐다.”
- “시간 협의 제안은 이미 확정된 근무다.”

한 문장: **Daytona is where our scheduling agent executes its planning tools.**
