# 3분 피치: 라이브 Harness 데모

PowerShell에서 실행:

```powershell
cd C:\Users\user\source\hacksprint\new_part_timetable-agent-harness
python pitch_demo.py
```

Daytona 인증이 설정된 현재 PC에서 실행한다. 실제 sandbox 실패 시 종료하며 로컬 실행으로 숨겨서 대체하지 않는다. Nosana 없이 결정론적 점수를 사용한다.

## 발표 순서

- 0:00–0:30: “퇴근 후 빈 시간에 어떤 일을 할 수 있을까요? 제공된 600개 합성 공고에서 시간·이동·사용자 조건을 비교합니다.”
- 0:30–1:00: 명령 실행. “Daytona 안에서 전체 데이터 로딩과 일정 가능성 검사를 실행합니다. 이동은 데모 추정치입니다.”
- 1:00–1:40: 첫 사례의 이동 → 근무 → 귀가, 예상 수입을 설명한다. “시간 협의 가능 공고에 대한 변경 제안이며, 고용주 확인 전 확정 일정은 아닙니다.”
- 1:40–2:15: 두 번째 사례. “선호를 매장 정리에서 물류로 바꾸자 선택된 공고와 예상 수입이 달라집니다.”
- 2:15–2:45: 세 번째 사례. “게시 시간을 고정하면 조건에 맞는 공고가 없습니다. 시스템은 없는 일정을 만들어내지 않습니다.”
- 2:45–3:00: “Daytona가 계획 도구를 실행하고, Harness가 적합도를 평가해 이동·수입을 포함한 JSON을 반환합니다.”

## 확인된 결과

실제 Daytona 실행으로 3/3 PASS. 한 sandbox를 재사용한다.

| 사례 | 예상 수입 | 귀가 | 결과 |
|---|---:|---|---|
| 토요일, 매장 정리 선호 | 52,680원 | 19:22 | 시간 변경 제안 |
| 토요일, 물류 선호 | 67,440원 | 19:26 | 시간 변경 제안 |
| 시간 협의 불허 | 0원 | 해당 없음 | 빈 일정 |

전체 실제 입력과 결과는 실행할 때마다 `.runtime/pitch/input-1.json` 및 `case-1.json`부터 3까지 저장된다. 저장된 결과는 재생용 참고 자료이며 새로운 라이브 실행 증거로 제시하지 않는다.

현재 데모는 일일 일정 CLI이다. HTTP API, 주간 복수 계획, 새 api-contract.md 연동 완료를 주장하지 않는다.
